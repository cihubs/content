# CIHUBS Content Repository

This repository contains all content for the CIHUBS website, managed via TinaCMS.

## Structure

- `blog/` - Blog posts and articles
- `programs/` - Program pages content
- `authors/` - Author profiles
- `pages/` - Static page content

## Usage

Content in this repository is consumed by the CIHUBS website at `https://github.com/cihubs/website`.

## Editing Content

Content is managed through TinaCMS. See the website repository for configuration details.
